## Wiring it in (your issue 2, tonight)

The repo has a skill for exactly this. Run `/ai-usage-setup` and choose Google. It will:
* Create `src/server/ai/google.ts`, the only file allowed to import `@google/genai`
* Add `'google'` to `AI_PROVIDERS`
* Register `gemini-3.5-flash-lite` → `google/gemini-3.5-flash-lite` in `OPENROUTER_SLUGS`
* Add a `GEMINI_API_KEY` through `src/lib/env.ts`

You get the key free from Google AI Studio.
