Most of this is already built, so the questions below are about what's still missing. I haven't changed anything yet.

**Already in place**
- **Sign-up, sign-in and sign-out:** these are in [auth.ts](src/server/actions/auth.ts), and they create the `User` row using the Supabase id.
- **Supabase settings:** the live settings show only `email` turned on, with every social provider off. `mailer_autoconfirm` is true, so Confirm email is off.
- **Redirects:** both pages send you to `/today` if you're already signed in, and `/today` sends you to `/sign-in` if you aren't.

**Still missing**
- **Wrong password ([#11](https://github.com/GroovierHen/kept/issues/11)):** the error doesn't say "Forgot it? Message us". A separate line on the sign-in page does mention resets, but it doesn't say how to reach you.
- **Taken email ([#11](https://github.com/GroovierHen/kept/issues/11)):** the message says to sign in but has no link.
- **Time zone and first Event ([#10](https://github.com/GroovierHen/kept/issues/10)):** sign-up doesn't save a time zone or record a "signed up" Event, and the `Event` table doesn't exist yet. Kept days and Day N both depend on the time zone.
- **Live URL ([#8](https://github.com/GroovierHen/kept/issues/8)):** this is still open, and `NEXT_PUBLIC_APP_URL` in `.env.local` points to localhost.

**Not checked:** the Supabase connection here lists no projects, so I couldn't look at the auth users or database. The settings above came from the project's public settings endpoint.
