Signing in now shows a loading animation all the way to the setup screen, instead of the page sitting still for several seconds. Your own dev log showed about 6 seconds between sign-in and setup.

**The animation:** I used a ledger-style tally rather than a generic spinner, since counting kept promises is what Kept does. Four gold strokes draw one at a time, a fifth crosses them, then it clears and starts again.

**What the user sees:**
1. **While signing in:** a small tally appears in the button next to "Signing you in". A wrong password only shows the error, with no full-screen loader.
2. **Once signed in:** a full-screen tally with "Getting Kept ready", lined up with the left edge of the setup card so nothing jumps when the card arrives. Sign-up works the same way.
3. **Other loads of `/setup` and `/today`:** they show the same loader, for example when opening `/today` from the daily reminder. It didn't appear when moving from the first setup question to the next.

With reduced motion turned on, it shows a still, finished tally.
