## What Kept is
A 2-minute-a-day money-habit coach based on Corley's *Rich Habits*. It checks whether people actually did what they said they'd do, and it teaches the money skill behind each habit using their own numbers.

- **Day 1:** sign up, then turn a dream into a plan (Claude does the plan and the user edits it). The user gets their first habit and skill, then picks a promise from a list ranked by pounds saved, and it goes into their calendar as an `.ics` reminder.
- **Every day after:** report back (Yes, Partly or No), answer a recall question (code works out the right answer, Claude marks it 0–2, and it falls back to multiple choice if Claude is down), learn a new habit, make a new promise.
- **Engines:** promise coach (ranks promises by £), adaptive ladder (small, medium and large actions), review scheduler (1, 3 and 7 days), and a ledger built from an event log.
- **AI in only three places:** making the plan, marking answers, and "Help me choose". All the maths and all the text is ours.
- **Deadlines:** the must tier is due **Fri Oct 30**, features freeze Tue Nov 3, and the final demo is Thu Nov 5. Testers need to start by Oct 30.

## Where the docs and the repo don't match
1. **Stack.** The proposal says SQLite + Better Auth on a laptop, with ngrok for testers' phones and a daily backup of the file. This repo uses the 8x template instead: Prisma + Supabase Postgres, Supabase Auth, deployed on Vercel. I'd keep the template. It already covers email and password login, long sessions and a logout button. Testers open a real URL on their phones, so the ngrok question ("ask 8x if that's allowed") and the backup worry both go away. The cost is the template's checks (CI-generated migrations, RLS checks), which need to be set up before Friday.
2. **Scheduler.** The proposal plans to reuse FSRS. The walkthrough uses fixed 1/3/7-day reviews, which is simpler and enough for a 9-day build.
3. **Models.** The AI usage map ([models.ts:38](src/server/lib/ai-usage/models.ts:38)) lists `claude-sonnet-5` and `claude-haiku-4-5`. To use Sonnet or Haiku 5.5 for planning and marking, each has to be added to `OPENROUTER_SLUGS` first.
4. **Setup isn't finished.** `package.json` is still named `template-web`, so `template-setup` seems only half done. The README is already about Kept.
